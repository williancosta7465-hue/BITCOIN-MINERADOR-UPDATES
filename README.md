# Bitcoin Minerador Solo — Canal de Atualizações

Este repositório público contém somente metadados e, futuramente, pacotes de atualização do Bitcoin Minerador Solo.

Não devem ser publicados aqui dados pessoais, configurações locais, logs, seed, chave privada, senha de carteira ou tokens.

O aplicativo consulta `latest.json` para verificar a versão disponível.
